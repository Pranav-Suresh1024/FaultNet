Reset discards pending edits and cancels active live requests. Live settings and traffic disappear when Node restarts. Saved experiments remain in the workbench.

04 Network dynamics

0 KiB/s means unlimited. Jitter varies each direction's delay by ± the chosen amount, clamped at zero. Limits shape body delivery, not IP packet loss.

05 Connection failures

Applies to each eligible response. HEAD and no-body responses remain legal. Stalled requests end on cancel/reset or at the 120-second ceiling.

06 Status injection

Path prefixes, HTTP errors 400–599, probability 0–100%. First matching selected rule wins, before mocks.

07 JSON response mocks

Return local JSON without contacting upstream. Eight rules maximum; 1024 bytes per body. Response faults still apply.
